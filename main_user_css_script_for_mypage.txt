[***# Cosense Zenn Style]
[Zenn https://zenn.dev/zenn/articles/markdown-guide] 風の見た目を Cosense (Scrapbox) で再現することを目指した UserCSS, UserScript, (Tampermonkey)
	(Github) https://github.com/Onely7/cosense-zenn-style

[**# UserCSS]

[*# 配色と寸法]
 色・本文幅・文字サイズは、このブロックの CSS 変数を書き換えるだけで調整できる
code:style.css

   /* 寸法 */
   --zs-page-width: 960px; /* 本文の最大幅（Cosense 標準と同じ） */
   --zs-toc-width: 240px; /* 広い画面で本文の横に表示する目次の幅 */
   --zs-font-size: 18px;
   --zs-line-height: 32px;
   --zs-letter-spacing: 0.5px;
   --zs-heading-indent: 18px; /* 見出しの左端から文字までの距離 */

[*# マーカー強調]
	`[! hoge moga]` → [! hoge moga]
	`[!* hoge moga]` → [!* hoge moga]
	`[[hoge moga]]` → [[hoge moga]]
code:style.css
 .deco-\! {
   color: var(--zs-marker-text);
   background-color: var(--zs-marker-bg); /* 黄背景 */
   padding: 0.1em 0.2em;
 }
 .level-1 .deco-\! {
   color: var(--zs-marker-strong-text); /* 白文字 */
   background-color: var(--zs-marker-strong-bg); /* 赤背景 */
   padding: 0.1em 0.2em;
 }
 
 /* 二重括弧は小見出しにしたい */
 .line strong:not([class]) {
   background-color: var(--zs-subheading-bg);
   padding: 0.2em 0.5em;
 }

[*# チェックボックス]
 `[_]` -> [_]
 `[x]` -> [x]
code:style.css
 /*
  * チェックボックスになるタグ（Font Awesome 版）。
  * Cosense のリンクは /プロジェクト名/_ の形になるため、href の末尾で判定する。
  * Font Awesome は Cosense 本体が読み込んでいるものを使う。
  */
 .line:not(.cursor-line) a.page-link[type="link"]:is([href$="/_"], [href$="/x"]):not(.icon) span {
   display: inline-block;
   width: 0;
   text-indent: -9999px;
 }
 .line:not(.cursor-line) a.page-link[type="link"]:is([href$="/_"], [href$="/x"]):not(.icon)::after {
   display: inline-block;
   min-width: 1.15em;
   padding-left: 1px;
   font-family: 'Font Awesome 5 Free';
   font-weight: 400;
   font-size: 120%;
   text-align: center;
   vertical-align: middle;
 }
 .line:not(.cursor-line) a.page-link[type="link"][href$="/_"]:not(.icon)::after {

 }

[*# GitHub ファイル埋め込み]
 GitHub 埋め込みは、Cosense の CSP 制約を避けるため、Tampermonkey 用の `cosense_github_embed_tampermonkey.user.js` 側で CSS と JavaScript を管理する。
 マイページの UserScript から GitHub Raw への `fetch()` は行わない。
 カードの幅と、コードを表示する部分の最大の高さは、[*# 配色と寸法] の `--zs-github-embed-width` と `--zs-github-embed-max-height` で変えられる

[*# X（Twitter）ポスト埋め込み]
 ポスト URL だけの行の下に、投稿者・本文・画像を載せたカードを表示する（UserScript で描画する）

 カードの幅は、[*# 配色と寸法] の `--zs-x-embed-width` で変えられる（Tampermonkey 版のカードにも使う）

[#* GitHub ファイル埋め込み]
 Cosense の CSP で GitHub（github.com・raw.githubusercontent.com）への通信が拒否され、ファイルの中身を中継する Cosense の API もないため、この機能は Tampermonkey 用 userscript で実行する。

[#* X（Twitter）ポスト埋め込み]
 X の公式ウィジェット（iframe）や X の API は Cosense の CSP で使えないため、Cosense がポスト URL の貼り付け時に使う API（/api/embed-text/twitter）から投稿者・本文・画像を取得して表示する
code:script.js
 // ブロック内の変数は、ほかの機能の変数と衝突しない
 {
   // ポスト URL だけの行（[ ] で囲んだ形も含む）
   const POST_LINE = /^\s*\[?(https?:\/\/(?:www\.|mobile\.)?(?:x|twitter)\.com\/(\w{1,15})\/status(?:es)?\/(\d+)\S*?)\]?\s*$/
   const CACHE_PREFIX = 'zs-x-post:'
   const X_LOGO = 'M18.244 2.25h3.308l-7.227 8.26 8.502 11.24H16.17l-5.214-6.817L4.99 21.75H1.68l7.73-8.835L1.254 2.25H8.08l4.713 6.231zm-1.161 17.52h1.833L7.084 4.126H5.117z'
   const TOKEN = /https?:\/\/[^\s]+|@\w{1,15}|#[\p{L}\p{N}_]+/gu
 
   // Cosense がポスト URL の貼り付け時に使う API（同じオリジンなので CSP に妨げられない）
   const requests = new Map()
   const fetchPost = (id, url) => {
     if (!requests.has(id)) {
       requests.set(id, (async () => {
         try {
           const cached = sessionStorage.getItem(CACHE_PREFIX + id)
           if (cached) return JSON.parse(cached)
         } catch {}
         const response = await fetch(`/api/embed-text/twitter?url=${encodeURIComponent(url)}`, {method: 'POST'})
         if (!response.ok) return null
         const data = await response.json()
         if (!data?.description && !data?.images?.length) return null
         try {
           sessionStorage.setItem(CACHE_PREFIX + id, JSON.stringify(data))
         } catch {}
         return data
       })().catch(() => null))
     }
     return requests.get(id)
   }
 
   const element = (tag, className, text) => {
     const node = document.createElement(tag)
     node.className = className
     if (text != null) node.textContent = text
     return node
   }
 
   const externalLink = (className, href, text) => {
     const link = element('a', className, text)
     link.href = href
     link.target = '_blank'
     link.rel = 'noopener noreferrer'
     return link
   }
 
   // 本文の URL・@ユーザー名・#ハッシュタグをリンクにする
   const appendText = (parent, text) => {
     let last = 0
     for (const match of text.matchAll(TOKEN)) {
       const [token] = match
       const before = text[match.index - 1] ?? ''
       if (token[0] !== 'h' && /[\p{L}\p{N}_]/u.test(before)) continue
       parent.append(text.slice(last, match.index))
       if (token[0] === '@') parent.append(externalLink('', `https://x.com/${token.slice(1)}`, token))
       else if (token[0] === '#') parent.append(externalLink('', `https://x.com/hashtag/${encodeURIComponent(token.slice(1))}`, token))
       else parent.append(externalLink('', token, token.replace(/^https?:\/\//, '')))
       last = match.index + token.length
     }
     parent.append(text.slice(last))
   }
 
   const createCard = (data, postUrl, fallbackName) => {
     const screenName = data.screenName || fallbackName
     const displayName = /^(.*) \(@\w+\)$/.exec(data.userName ?? '')?.[1] || screenName
     const card = element('div', 'zs-x-card')
 
     const header = element('div', 'zs-x-header')
     const avatar = element('span', 'zs-x-avatar', [...displayName.trim()][0]?.toUpperCase() ?? 'X')
     const names = externalLink('zs-x-names', `https://x.com/${screenName}`)
     names.append(element('span', 'zs-x-name', displayName), element('span', 'zs-x-screen-name', `@${screenName}`))
     const logo = document.createElementNS('http://www.w3.org/2000/svg', 'svg')
     logo.setAttribute('class', 'zs-x-logo')
     logo.setAttribute('viewBox', '0 0 24 24')
     logo.setAttribute('aria-hidden', 'true')
     logo.innerHTML = `<path d="${X_LOGO}"/>`
     header.append(avatar, names, logo)
     card.append(header)
 
     if (data.description) {
       const text = element('p', 'zs-x-text')
       appendText(text, data.description)
       card.append(text)
     }
 
     const images = (data.images ?? []).slice(0, 4)
     if (images.length > 0) {
       const media = element('div', 'zs-x-media')
       media.dataset.count = images.length
       for (const src of images) {
         const link = externalLink('zs-x-media-item', postUrl)
         const image = document.createElement('img')
         image.src = src
         image.alt = ''
         image.loading = 'lazy'
         image.decoding = 'async'
         image.referrerPolicy = 'no-referrer'
         link.append(image)
         media.append(link)
       }
       card.append(media)
     }
 
     card.append(externalLink('zs-x-footer', postUrl, 'X でポストを見る'))
     return card
   }
 
   // Tampermonkey 版（cosense_x_post_embed_tampermonkey.user.js）が動いているときは、そちらに任せる
   let hasTampermonkeyVersion = false
   const detectTampermonkeyVersion = () => {
     hasTampermonkeyVersion ||= [...document.querySelectorAll('style')]
       .some(style => style.textContent.includes('.x-static-card'))
     return hasTampermonkeyVersion
   }
 
   const render = () => {
     const targets = new Map()
     if (scrapbox.Layout === 'page' && !detectTampermonkeyVersion()) {
       for (const line of scrapbox.Page.lines ?? []) {
         if (line.codeBlock || line.tableBlock) continue
         const match = POST_LINE.exec(line.text)
         if (match) targets.set(`L${line.id}`, {screenName: match[2], id: match[3]})
       }
     }
 
     // ポスト URL だけの行でなくなったときは、カードを消す
     for (const host of document.querySelectorAll('.zs-x-embed')) {
       const target = targets.get(host.parentElement?.id)
       if (!target || target.id !== host.dataset.id) host.remove()
     }
 
     for (const [lineId, target] of targets) {
       const line = document.getElementById(lineId)
       if (!line || line.querySelector(':scope > .zs-x-embed')) continue
       const host = element('div', 'zs-x-embed')
       host.dataset.id = target.id
       const text = line.querySelector(':scope > .text')
       if (text) text.after(host)
       else line.append(host)
       const postUrl = `https://x.com/${target.screenName}/status/${target.id}`
       fetchPost(target.id, postUrl).then(data => {
         if (!data || !host.isConnected) return
         host.replaceChildren(createCard(data, postUrl, target.screenName))
         host.classList.add('is-ready')
       })
     }
   }
 
   let renderTimer = 0
   const scheduleRender = (delay = 300) => {
     clearTimeout(renderTimer)
     renderTimer = setTimeout(render, delay)
   }
 
   // Tampermonkey 版があとから読み込まれたときは、こちらのカードを消して譲る
   new MutationObserver(() => {
     if (!hasTampermonkeyVersion && detectTampermonkeyVersion()) scheduleRender(0)
   }).observe(document.head, {childList: true})
 
   scrapbox.on('lines:changed', () => scheduleRender())
   scrapbox.on('page:changed', () => scheduleRender(0))
   scrapbox.on('layout:changed', () => scheduleRender(0))
   scheduleRender(0)
 }

[#* 見出しの判定]
	from: [/daiiz/ページの見出しを作るUserScript]
 `[*# 見出し]` のように `#` を含む太字だけの行を見出しとし、`*` の数に応じて階層を付ける（目次と見出しリンクのコピーで使う）
 `#` を含む見出しがないページでは、`[** 見出し]` のように太字だけの行を使う
code:script.js
 /*
  * ページ内の見出しを集める。
  * level は * の数、depth は最上位の見出しを 0 とした階層の深さ。
  * 目次と見出しリンクのコピーで使う。
  */
 function getHeadings () {
   const candidates = []
   for (const line of scrapbox.Page.lines ?? []) {
     if (line.title || !line.nodes) continue
     const node = getHeadingNode(line.nodes)
     if (!node) continue
     const text = renderPlainText(node.children, {noIcon: true}).trim()
     const textWithIcons = renderPlainText(node.children, {noIcon: false}).trim()
     candidates.push({
       id: line.id,
       level: node.type === 'strong' ? 1 : node.unit.strong,
       hasHash: node.type === 'deco' && node.unit.deco.includes('#'),
       text: text || textWithIcons
     })
   }
   const headings = candidates.some(heading => heading.hasHash)
     ? candidates.filter(heading => heading.hasHash)
     : candidates
   const top = Math.max(...headings.map(heading => heading.level))
   for (const heading of headings) heading.depth = Math.min(top - heading.level, 3)
   return headings
 }
 
 // 行の中身が太字の装飾（[* ...] や [[...]]）1 つだけのとき、その装飾を返す
 function getHeadingNode (nodes) {
   const list = (Array.isArray(nodes) ? nodes : [nodes])
     .filter(node => typeof node !== 'string' || node.trim() !== '')
   if (list.length !== 1) return null
   const [node] = list
   if (node.type === 'indent') return getHeadingNode(node.children)
   if (node.type === 'strong') return node
   if (node.type === 'deco' && node.unit.strong > 0) return node
   return null
 }
 
 function renderPlainText (node, options) {
   if (node == null) return ''
   if (Array.isArray(node)) return node.map(child => renderPlainText(child, options)).join('')
   if (typeof node === 'string') return node
   switch (node.type) {
     case 'icon':
     case 'strong-icon':
       return options.noIcon ? ' ' : node.unit.page
     case 'hashTag':
       return ''
   }
   return renderPlainText(node.children, options)
 }
 
 // 行リンク（#行ID）で移動する。すでに同じ行リンクを開いているときは、その行までスクロールする
 function jumpToLine (id) {
   if (location.hash !== `#${id}`) {
     location.hash = id
     return
   }
   const line = document.getElementById(`L${id}`)
   if (line) window.scrollTo({top: line.getBoundingClientRect().top + window.scrollY - 100, behavior: 'smooth'})
 }

     '<path d="M20 6 9 17l-5-5"/>',
     '</svg>'
   ].join('')
   document.body.append(button)
 
   let headingIds = new Set()
   let current = null
   let hideTimer = 0
   let resetTimer = 0
 
   const headingLineOf = target => {
     const line = target instanceof Element ? target.closest('.lines .line') : null
     return line && headingIds.has(line.id.slice(1)) ? line : null
   }
 
   const hide = () => {
     clearTimeout(hideTimer)
     button.hidden = true
     current = null
   }
 
   const show = line => {
     clearTimeout(hideTimer)
     if (document.querySelector('.app.presentation')) return
     if (line === current && !button.hidden) return
     current = line
     button.classList.remove('is-copied', 'is-failed')
     const box = (line.querySelector('.deco-\\#, strong') ?? line).getBoundingClientRect()
     const narrow = window.matchMedia('(max-width: 767px)').matches
     const left = narrow ? line.getBoundingClientRect().right - SIZE : box.left - SIZE - 6
     const top = box.top + Math.max(0, (box.height - SIZE) / 2)
     button.style.left = `${Math.round(left + window.scrollX)}px`
     button.style.top = `${Math.round(top + window.scrollY)}px`
     button.hidden = false
   }
 
   let refreshTimer = 0
   const refresh = () => {
     clearTimeout(refreshTimer)
     refreshTimer = setTimeout(() => {
       headingIds = new Set(scrapbox.Layout === 'page' ? getHeadings().map(heading => heading.id) : [])
       if (current && !headingLineOf(current)) hide()
     }, 200)
   }
 
   const copyText = async text => {
     try {
       await navigator.clipboard.writeText(text)
       return true
     } catch {
       const textarea = document.createElement('textarea')
       textarea.value = text
       textarea.setAttribute('readonly', '')
       textarea.style.cssText = 'position: fixed; top: 0; left: 0; opacity: 0;'
       document.body.append(textarea)
       textarea.select()
       const copied = document.execCommand('copy')
       textarea.remove()
       return copied
     }
   }
 
   document.addEventListener('pointerover', event => {
     if (event.pointerType !== 'mouse') return
     if (button.contains(event.target)) {
       clearTimeout(hideTimer)
       return
     }
     const line = headingLineOf(event.target)
     if (line) {
       show(line)
     } else if (!button.hidden) {
       clearTimeout(hideTimer)
       hideTimer = setTimeout(hide, 400)
     }
   })
 
   // タッチ操作では、タップして編集中になった見出しにボタンを表示する
   document.addEventListener('pointerup', event => {
     if (event.pointerType === 'mouse' || button.contains(event.target)) return
     setTimeout(() => {
       const line = headingLineOf(document.querySelector('.lines .line.cursor-line'))
       if (line) show(line)
       else hide()
     }, 100)
   })
 
   button.addEventListener('click', async () => {
     if (!current) return
     const copied = await copyText(`${location.origin}${location.pathname}#${current.id.slice(1)}`)
     button.dataset.message = copied ? 'コピーしました' : 'コピーできませんでした'
     button.classList.toggle('is-copied', copied)
     button.classList.toggle('is-failed', !copied)
     clearTimeout(resetTimer)
     resetTimer = setTimeout(() => button.classList.remove('is-copied', 'is-failed'), 1500)
   })
 
   window.addEventListener('resize', hide)
   scrapbox.on('lines:changed', refresh)
   scrapbox.on('layout:changed', refresh)
   scrapbox.on('page:changed', () => {
     hide()
     refresh()
   })
   refresh()
 }

[#* Emoji (絵文字)]
	from: [/yutaro/emoji selector]
 `:` に続けて名前を入力すると、アイコン（絵文字）の候補を表示する
	↑↓ または Ctrl+P / Ctrl+N で選択、Enter または Tab で挿入、Esc で閉じる。`:名前:` と入力しても挿入できる
	英数字の直後の `:`（URL の `https:` や時刻の `12:30` など）では候補を出さない

     event.preventDefault()

   }

     const input = document.getElementById('text-input')
     const length = query.length + 1 // 「:」と、その後に入力した名前の文字数
     close()
     if (!input || !emoji) return
     input.focus()
     setTimeout(() => {
       for (let i = 0; i < length; i++) {
         const event = document.createEvent('Events')
         event.initEvent('keydown', true, true)
         event.keyCode = event.which = 8 // Backspace
         input.dispatchEvent(event)
       }

       menu.hidden = true
       return

       return

     return before === '' || /\s/.test(before) || !/[\x21-\x7e]/.test(before)
   }

     event.preventDefault()
     event.stopPropagation()

         query = ''
         selected = 0

       }

       } else {

     }

       if (key === ' ' && query === '') {
         close()
         return
       }
       query += key
       selected = 0
       requestAnimationFrame(render)
       return
     }
 
     if (['Shift', 'Control', 'Alt', 'Meta', 'CapsLock'].includes(key)) return
     close()
   }, true)
 
   // 候補の外をクリックしたときや、ページを移動したときは閉じる

     if (active && !menu.contains(event.target)) close()
   }, true)

       } catch (error) {

       }
     }
   })

[#* ページのダウンロード]
 ページメニューの「ダウンロード」から、表示中のページを Cosense 形式（.txt）か Markdown 形式（.md）で保存する
 Markdown 形式は、ブラウザ内で Cosense の記法を Markdown に変換してから保存する（見出しは目次と同じ規則で判定し、コードブロックは Zenn と同じ `言語:ファイル名` の形式にする）
 狭い画面では Cosense がページメニューの拡張ボタンを一部しか表示しないため、ヘッダーのボタンで開く目次の下部にもダウンロードボタンを置く

 // ブロック内の変数は、ほかの機能の変数と衝突しない
 {
   // Material Symbols（Apache License 2.0）の download アイコン
   const DOWNLOAD_ICON = `data:image/svg+xml,${encodeURIComponent('<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 -960 960 960"><path fill="#000" d="M480-320 280-520l56-58 104 104v-326h80v326l104-104 56 58-200 200ZM240-160q-33 0-56.5-23.5T160-240v-120h80v120h480v-120h80v120q0 33-23.5 56.5T720-160H240Z"/></svg>')}`
 
   const DECO = /^\[([!"#%&'()*+,\-./{|}<>_~]+) ((?:\[[^[\]]+\]|[^\]])+)\]/
   const BRACKET = /^\[([^[\]]+)\]/
   const URL_ONLY = /^https?:\/\/\S+$/
   const IMAGE_URL = /^https?:\/\/\S+\.(?:png|jpe?g|gif|svg|webp|avif|bmp)(?:[?#]\S*)?$/i
   const GYAZO_URL = /^https:\/\/(?:i\.)?gyazo\.com\/[0-9a-f]{32}(?:\/raw|\.\w+)?$/i
   const ICON = /^(.+)\.icon(?:\*(\d+))?$/
   const TASK = /^\[([_x])\](?:\s+|$)/
   const CLI = /^[$%] \S/
   const OPEN = '\uE000' // 強調の開始位置の目印（書き出しの最後に取り除く）
   const CLOSE = '\uE001' // 強調の終了位置の目印
   const MAP = /^([NS])(\d+(?:\.\d+)?),([EW])(\d+(?:\.\d+)?)(?:,Z(\d+))?(?:\s+(.+))?$/
 
   const indentOf = text => /^[ \t]*/.exec(text)[0].length
 
   // ---- Cosense の記法を読み取る ----
 
   // 1 行分の文字列を、記法ごとのノードに分ける
   const parseInline = text => {
     const nodes = []
     let plain = ''
     const push = node => {
       if (plain) nodes.push({type: 'text', text: plain})
       plain = ''
       nodes.push(node)
     }
     let index = 0
     while (index < text.length) {
       const rest = text.slice(index)
       const char = text[index]
       let match
       if (char === '`') {
         // コードの中の \` は、閉じ記号ではなくバッククオートそのもの（Cosense と同じ）
         let end = index + 1
         while (end < text.length && text[end] !== '`') end += text[end] === '\\' && text[end + 1] === '`' ? 2 : 1
         if (end < text.length) {
           push({type: 'code', text: text.slice(index + 1, end).replace(/\\`/g, '`')})
           index = end + 1
           continue
         }
       } else if (char === '[') {
         const token = parseBracket(rest)
         if (token) {
           push(token.node)
           index += token.length
           continue
         }
       } else if (char === '#' && (index === 0 || /\s/.test(text[index - 1])) && (match = /^#(\S+)/.exec(rest))) {
         push({type: 'hashtag', page: match[1]})
         index += match[0].length
         continue
       } else if (char === 'h' && (match = /^https?:\/\/[^\s　]+/.exec(rest))) {
         push({type: 'url', url: match[0]})
         index += match[0].length
         continue
       }
       plain += char
       index += 1
     }
     if (plain) nodes.push({type: 'text', text: plain})
     return nodes
   }
 
   const parseBracket = rest => {
     if (rest.startsWith('[[')) {
       const end = rest.indexOf(']]', 2)
       const content = end > 2 ? rest.slice(2, end) : ''
       if (content && !/[[\]]/.test(content)) return {node: classifyStrong(content), length: end + 2}
     }
     if (rest.startsWith('[$ ')) {
       // 数式の中の [ ] は、対応する組を数えて読み飛ばす
       let depth = 0
       for (let index = 0; index < rest.length; index++) {
         if (rest[index] === '[') depth += 1
         else if (rest[index] === ']' && --depth === 0) {
           return {node: {type: 'formula', text: rest.slice(3, index).trim()}, length: index + 1}
         }
       }
     }
     let match = DECO.exec(rest)
     if (match) return {node: {type: 'deco', chars: match[1], children: parseInline(match[2])}, length: match[0].length}
     match = BRACKET.exec(rest)
     if (match) return {node: classifyBracket(match[1]), length: match[0].length}
     return null
   }
 
   const isImage = url => IMAGE_URL.test(url) || GYAZO_URL.test(url)
 
   // [[...]] は太字。中身がアイコンや画像のときは大きく表示する記法
   const classifyStrong = content => {
     const icon = ICON.exec(content)
     if (icon) return {type: 'icon', page: icon[1], times: 1}
     if (URL_ONLY.test(content) && isImage(content)) return {type: 'image', src: content}
     return {type: 'strong', children: [{type: 'text', text: content}]}
   }
 
   const classifyBracket = content => {
     if (!content.trim()) return {type: 'text', text: content}
     let match = ICON.exec(content)
     if (match) return {type: 'icon', page: match[1], times: Math.min(Number(match[2] ?? 1), 20)}
     match = MAP.exec(content)
     if (match) {
       const lat = (match[1] === 'S' ? '-' : '') + match[2]
       const lng = (match[3] === 'W' ? '-' : '') + match[4]
       return {type: 'map', lat, lng, zoom: match[5] ?? '14', name: match[6] ?? `${match[1]}${match[2]},${match[3]}${match[4]}`}
     }
     if (URL_ONLY.test(content)) return isImage(content) ? {type: 'image', src: content} : {type: 'url', url: content}
     match = /^(https?:\/\/\S+)\s+(.+)$/.exec(content) ?? /^(.+?)\s+(https?:\/\/\S+)$/.exec(content)
     if (match) {
       const [url, label] = URL_ONLY.test(match[1]) ? [match[1], match[2]] : [match[2], match[1]]
       if (isImage(url) && URL_ONLY.test(label)) return {type: 'image', src: url, href: label}
       if (isImage(label) && URL_ONLY.test(label)) return {type: 'image', src: label, href: url}
       return {type: 'urlLink', url, text: label}
     }
     if (content.startsWith('/')) return {type: 'projectLink', path: content}
     return {type: 'link', page: content}
   }
 
   // ---- Markdown へ書き出す ----
 
   const createWriter = ({project, origin, icons = new Map()}) => {
     // Markdown のリンク先で問題になる空白・括弧だけをエスケープする
     const destination = url => url.replace(/[\s()<>]/g, char => `%${char.charCodeAt(0).toString(16).toUpperCase().padStart(2, '0')}`)
     const pageUrl = (projectName, page) =>
       destination(`${origin}/${encodeURIComponent(projectName)}/${encodeURIComponent(page.replace(/ /g, '_'))}`)
     const projectUrl = path => {
       const [, projectName, ...page] = path.split('/')
       return page.length
         ? pageUrl(projectName, page.join('/'))
         : destination(`${origin}/${encodeURIComponent(projectName)}`)
     }
     const iconPage = page => {
       const match = /^\/([^/]+)\/(.+)$/.exec(page)
       return match ? {projectName: match[1], title: match[2]} : {projectName: project, title: page}
     }
 
     // 書式として解釈される記号をエスケープする
     const escapeText = (text, atStart = false) => {
       let result = text
         .replace(/\\(?=[!-/:-@[-`{-~])/g, '\\\\')
         .replace(/[`*[\]<$~]/g, '\\$&')
         .replace(/&(?=#?\w+;)/g, '&amp;')
         .replace(/_/g, (char, offset, all) =>
           /[A-Za-z0-9]/.test(all[offset - 1] ?? '') && /[A-Za-z0-9]/.test(all[offset + 1] ?? '') ? char : '\\_')
       if (atStart) {
         result = result
           .replace(/^(#{1,6})(?=\s|$)/, '\\$1')
           .replace(/^[>+=-]/, '\\$&')
           .replace(/^(\d{1,9})([.)])(?=\s|$)/, '$1\\$2')
       }
       return result
     }
 
     const codeSpan = text => {
       const longest = Math.max(0, ...(text.match(/`+/g) ?? []).map(run => run.length))
       const fence = '`'.repeat(longest + 1)
       const padding = text.startsWith('`') || text.endsWith('`') ? ' ' : ''
       return `${fence}${padding}${text}${padding}${fence}`
     }
 
     const renderNodes = (nodes, context = {}) => nodes.reduce((result, node, index) => {
       const piece = renderNode(node, {...context, atStart: Boolean(context.atStart) && index === 0})
       // 「!」の直後にリンクが続くと画像の記法になってしまうため、「!」をエスケープする
       return (piece.startsWith('[') && /(?<!\\)!$/.test(result) ? `${result.slice(0, -1)}\\!` : result) + piece
     }, '')
 
     // 装飾の種類（Markdown で同じ記号になるもの）
     const emphasisKind = node => {
       if (node.type === 'strong') return '**'
       if (node.type !== 'deco') return null
       const bold = node.chars.includes('*') || node.chars.includes('!')
       const kind = (bold ? '**' : '') + (node.chars.includes('/') ? '*' : '') + (node.chars.includes('-') ? '~~' : '')
       return kind || null
     }
 
     // [* a][* b] のように同じ装飾が続くと **a****b** となり強調にならないため、1 つにまとめる
     const mergeEmphasis = nodes => nodes.reduce((result, node) => {
       const previous = result[result.length - 1]
       const kind = emphasisKind(node)
       if (kind && previous && emphasisKind(previous) === kind) {
         result[result.length - 1] = {...previous, children: [...previous.children, ...node.children]}
       } else {
         result.push(node)
       }
       return result
     }, [])
 
     // 1 行分を書き出す。CommonMark では、強調の記号の内側が記号（「 や [ など）で外側が文字のとき、
     // 強調にならない（日本語の文中で起きやすい）ため、そうなる位置だけ記号の外側に空白を入れる
     const isPunctuation = char => /[\p{P}\p{S}]/u.test(char)
     const isWordChar = char => char !== undefined && !/\s/u.test(char) && !isPunctuation(char)
     const isSentinel = char => char === OPEN || char === CLOSE
     const renderInline = (nodes, context = {}) => {
       const chars = Array.from(renderNodes(mergeEmphasis(nodes), context))
       const output = []
       const lastChar = () => {
         for (let index = output.length - 1; index >= 0; index -= 1) if (output[index]) return output[index]
         return undefined
       }
       chars.forEach((char, index) => {
         if (char === OPEN) {
           // 最初の記号の並び（~~ や ** など）の直後の文字を調べる
           let next = index + 1
           while (isSentinel(chars[next])) next += 1
           const mark = chars[next]
           while (chars[next] === mark || isSentinel(chars[next])) next += 1
           output.push(isPunctuation(chars[next] ?? ' ') && isWordChar(lastChar()) ? ' ' : '')
         } else if (char === CLOSE) {
           // 最後の記号の並びの直前の文字を調べる
           let previous = output.length - 1
           while (previous >= 0 && !output[previous]) previous -= 1
           const mark = output[previous]
           while (previous >= 0 && (output[previous] === mark || !output[previous])) previous -= 1
           let next = index + 1
           while (isSentinel(chars[next])) next += 1
           output.push(isPunctuation(output[previous] ?? ' ') && isWordChar(chars[next]) ? ' ' : '')
         } else {
           output.push(char)
         }
       })
       return output.join('')
     }
 
     // 中身の先頭と末尾の空白・記号（「」など）は ** の外に出す
     const renderEmphasis = (children, open, close, context) => {
       // 画像やアイコンだけを囲む装飾は、Markdown では意味がないため付けない
       if (children.every(node => ['image', 'icon'].includes(node.type) || (node.type === 'text' && !node.text.trim()))) {
         return renderNodes(children, context)
       }
       const nodes = children.map(node => ({...node}))
       const first = nodes[0]
       const last = nodes[nodes.length - 1]
       let before = ''
       let after = ''
       if (first?.type === 'text') {
         before = /^[\s\p{P}\p{S}]*/u.exec(first.text)[0]
         first.text = first.text.slice(before.length)
       }
       if (last?.type === 'text') {
         after = /[\s\p{P}\p{S}]*$/u.exec(last.text)[0]
         last.text = last.text.slice(0, last.text.length - after.length)
       }
       const body = renderInline(nodes.filter(node => node.type !== 'text' || node.text !== ''))
       if (!body) return renderNodes(children, context)
       return `${escapeText(before, context.atStart)}${OPEN}${open}${body}${close}${CLOSE}${escapeText(after)}`
     }
 
     const renderNode = (node, context) => {
       switch (node.type) {
         case 'text':
           return escapeText(node.text, context.atStart)
         case 'code':
           return codeSpan(node.text)
         case 'formula':
           return `$${node.text}$`
         case 'strong':
           return renderEmphasis(node.children, '**', '**', context)
         case 'deco': {
           const bold = node.chars.includes('*') || node.chars.includes('!')
           const italic = node.chars.includes('/')
           const strike = node.chars.includes('-') ? '~~' : ''
           const emphasis = (bold ? '**' : '') + (italic ? '*' : '')
           if (!emphasis && !strike) return renderNodes(node.children, context)
           return renderEmphasis(node.children, strike + emphasis, emphasis + strike, context)
         }
         case 'link':
           // [_] と [x] は、この UserCSS でチェックボックスとして表示する記法
           if (node.page === '_' || node.page === 'x') return node.page === 'x' ? '☑' : '☐'
           return `[${escapeText(node.page)}](${pageUrl(project, node.page)})`
         case 'projectLink':
           return `[${escapeText(node.path)}](${projectUrl(node.path)})`
         case 'hashtag':
           return `[#${escapeText(node.page)}](${pageUrl(project, node.page)})`
         case 'url':
           // 1 行に URL だけがあるときは、Zenn などでリンクカードになるようにそのまま書く
           if (context.wholeLine) return node.url
           return /[\s<>]/.test(node.url) ? `[${escapeText(node.url)}](${destination(node.url)})` : `<${node.url}>`
         case 'urlLink':
           return `[${escapeText(node.text)}](${destination(node.url)})`
         case 'image': {
           // Cosense にアップロードした画像は、ほかのサイトからは表示できないため、リンクにする
           if (/^https:\/\/scrapbox\.io\/files\//.test(node.src)) {
             return `[${escapeText(node.src.split('/').pop())}](${destination(node.href ?? node.src)})`
           }
           const src = /^https:\/\/gyazo\.com\/[0-9a-f]{32}$/i.test(node.src) ? `${node.src}/raw` : node.src
           const image = `![](${destination(src)})`
           return node.href ? `[${image}](${destination(node.href)})` : image
         }
         case 'icon': {
           // 画像を表示できるアイコンは小さな画像に、できないアイコンはページへのリンクにする
           const {projectName, title} = iconPage(node.page)
           const image = icons.get(`${projectName}/${title}`)
           if (image) return `![${escapeText(title)}](${destination(image)})`.repeat(node.times)
           return `[${escapeText(title)}](${pageUrl(projectName, title)})`
         }
         case 'map':
           return `[${escapeText(node.name)}](https://www.google.com/maps/@${node.lat},${node.lng},${node.zoom}z)`
       }
       return ''
     }
 
     return {escapeText, codeSpan, renderInline, iconPage}
   }
 
   // 太字だけの行を見出しとして扱う（ページ内目次と同じ規則）
   const findHeadings = blocks => {
     const candidates = []
     blocks.forEach((block, index) => {
       if (block.type !== 'line') return
       const nodes = parseInline(block.content).filter(node => node.type !== 'text' || node.text.trim() !== '')
       if (nodes.length !== 1) return
       const [node] = nodes
       if (node.type === 'strong') candidates.push({index, node, level: 1, hasHash: false})
       if (node.type === 'deco' && node.chars.includes('*')) {
         candidates.push({index, node, level: node.chars.split('*').length - 1, hasHash: node.chars.includes('#')})
       }
     })
     const headings = candidates.some(heading => heading.hasHash)
       ? candidates.filter(heading => heading.hasHash)
       : candidates
     const top = Math.max(...headings.map(heading => heading.level))
     return new Map(headings.map(heading => [heading.index, {node: heading.node, level: Math.min(top - heading.level, 4) + 2}]))
   }
 
   const parseCodeName = name => {
     let match = /^(.*?)\s*\(([^()\s]+)\)$/.exec(name)
     if (match) return {lang: match[2], filename: match[1]}
     match = /\.([^.\s]+)$/.exec(name)
     if (match) return {lang: match[1], filename: name}
     return {lang: name, filename: ''}
   }
 
   // Cosense のページ（1 行目がタイトル）を Markdown に変換する
   const cosenseToMarkdown = (texts, options) => {
     const writer = createWriter(options)
     const {escapeText, codeSpan, renderInline, iconPage} = writer
     const [title = '', ...body] = texts
 
     // コードブロックと表は、まとまりとして読み取る
     const blocks = []
     for (let index = 0; index < body.length;) {
       const indent = indentOf(body[index])
       const content = body[index].slice(indent)
       const code = /^code:(.+)$/.exec(content)
       const table = /^table:(.*)$/.exec(content)
       if (!code && !table) {
         blocks.push({type: 'line', indent, content})
         index += 1
         continue
       }
       let end = index + 1
       while (end < body.length && indentOf(body[end]) > indent) end += 1
       const rows = body.slice(index + 1, end).map(row => row.slice(indent + 1))
       blocks.push(code
         ? {type: 'code', indent, name: code[1].trim(), rows}
         : {type: 'table', indent, title: table[1].trim(), rows})
       index = end
     }
     const headings = findHeadings(blocks)
 
     const fenced = (info, rows) => {
       const longest = Math.max(0, ...rows.flatMap(row => (row.match(/`+/g) ?? []).map(run => run.length)))
       const fence = '`'.repeat(Math.max(3, longest + 1))
       return [fence + info, ...rows, fence]
     }
 
     const renderCode = block => {
       const {lang, filename} = parseCodeName(block.name)
       return fenced(filename ? `${lang}:${filename}` : lang, block.rows)
     }
 
     const renderTable = block => {
       const lines = block.title ? [`**${escapeText(block.title)}**`] : []
       const rows = block.rows
         .filter(row => row.trim() !== '')
         .map(row => row.split('\t').map(cell => renderInline(parseInline(cell.trim())).replace(/\|/g, '\\|')))
       const width = Math.max(0, ...rows.map(row => row.length))
       if (width === 0) return lines
       const cells = row => [...row, ...Array(width - row.length).fill('')].join(' | ')
       const [head, ...rest] = rows
       return [...lines, ...(lines.length ? [''] : []),
         `| ${cells(head)} |`, `|${' --- |'.repeat(width)}`, ...rest.map(row => `| ${cells(row)} |`)]
     }
 
     // 1 行分の中身を {kind, lines} にする
     const renderLine = (block, index, inList) => {
       const heading = headings.get(index)
       if (heading) {
         const text = renderInline(heading.node.children).trim()
         if (text) return {kind: 'heading', lines: [`${'#'.repeat(heading.level)} ${text}`]}
       }
       const {content} = block
       if (content.startsWith('>')) {
         const quote = renderInline(parseInline(content.slice(1).replace(/^ /, '')), {atStart: true})
         return {kind: 'quote', lines: [quote ? `> ${quote}` : '>']}
       }
       if (CLI.test(content)) return {kind: 'para', lines: [codeSpan(content)]}
       const nodes = parseInline(content)
       const [node] = nodes
       if (nodes.length === 1 && !inList) {
         if (node.type === 'formula') return {kind: 'math', lines: ['$$', node.text, '$$']}
         // [/icons/hr.icon] だけの行は区切り線にする
         if (node.type === 'icon' && iconPage(node.page).projectName === 'icons' && iconPage(node.page).title === 'hr') {
           return {kind: 'rule', lines: ['---']}
         }
         // URL・画像・アイコンだけの行は、それだけの段落にする（Zenn などで URL がリンクカードになる）
         if (['url', 'image', 'icon'].includes(node.type)) {
           return {kind: 'media', lines: [renderInline(nodes, {atStart: true, wholeLine: true})]}
         }
       }
       return {kind: 'para', lines: [renderInline(nodes, {atStart: true})]}
     }
 
     const output = [`# ${escapeText(title)}`]
     let lastKind = 'heading'
     let listOffsets = [] // 各階層の箇条書きで、本文が始まる位置
     const emit = (kind, lines) => {
       // 続けて書いた行は、Cosense と同じように改行して表示されるよう、行末に空白を 2 つ付ける
       if (!['para', 'list', 'quote'].includes(kind) || kind !== lastKind) output.push('')
       else if (kind !== 'list') output[output.length - 1] += '  '
       output.push(...lines)
       lastKind = kind
       if (kind !== 'list') listOffsets = []
     }
 
     for (let index = 0; index < blocks.length; index += 1) {
       const block = blocks[index]
       if (block.type === 'line' && block.content === '') {
         lastKind = 'blank'
         continue
       }
       // 行頭が $ や % の行（コマンドライン）が続くときは、まとめてコードブロックにする
       if (block.type === 'line' && block.indent === 0 && CLI.test(block.content) && !headings.has(index)) {
         const commands = [block.content]
         while (blocks[index + 1]?.type === 'line' && blocks[index + 1].indent === 0 && CLI.test(blocks[index + 1].content)) {
           index += 1
           commands.push(blocks[index].content)
         }
         emit('code', fenced('console', commands))
         continue
       }
       // [_] と [x] で始まる行（この UserCSS でチェックボックスとして表示する記法）は、タスクリストにする。
       // 見出しはインデントされていても箇条書きにしない
       const isHeading = headings.has(index)
       const task = block.type === 'line' && !isHeading && TASK.exec(block.content)
       const inList = !isHeading && (block.indent > 0 || Boolean(task))
       let rendered
       if (block.type === 'code') rendered = {kind: 'code', lines: renderCode(block)}
       else if (block.type === 'table') rendered = {kind: 'table', lines: renderTable(block)}
       else rendered = renderLine(block, index, inList)
       if (rendered.lines.length === 0) continue
       if (!inList) {
         emit(rendered.kind, rendered.lines)
         continue
       }
 
       // インデントされた行は箇条書きにする。階層は 1 段ずつしか深くしない
       const depth = Math.min(Math.max(block.indent - 1, 0), listOffsets.length)
       const numbered = block.type === 'line' && rendered.kind === 'para' && /^(\d{1,9})\. (.*)$/.exec(block.content)
       let lines = rendered.lines
       let marker = '-'
       if (task) {
         const rest = renderInline(parseInline(block.content.slice(task[0].length)))
         lines = [`[${task[1] === 'x' ? 'x' : ' '}]${rest ? ` ${rest}` : ''}`]
       } else if (numbered) {
         marker = `${numbered[1]}.`
         lines = [renderInline(parseInline(numbered[2]), {atStart: true})]
       }
       const prefix = `${' '.repeat(depth === 0 ? 0 : listOffsets[depth - 1])}${marker} `
       const offsets = listOffsets.slice(0, depth)
       emit('list', lines.map((line, lineIndex) => {
         if (lineIndex === 0) return prefix + line
         return line === '' ? '' : ' '.repeat(prefix.length) + line
       }))
       listOffsets = [...offsets, prefix.length]
     }
 
     return `${output.join('\n').trim()}\n`
   }
 
   // ---- ページメニュー ----
 
   const toFileName = (title, extension) => {
     const name = title.replace(/[\\/:*?"<>|\u0000-\u001f]/g, '_').replace(/^\.+/, '_').trim().slice(0, 120)
     return `${name || 'untitled'}.${extension}`
   }
 
   const save = (text, fileName, type) => {
     const url = URL.createObjectURL(new Blob([text], {type}))
     const link = document.createElement('a')
     link.href = url
     link.download = fileName
     document.body.append(link)
     link.click()
     link.remove()
     setTimeout(() => URL.revokeObjectURL(url), 10000)
   }
 
   // アイコンのページの画像を調べる。Gyazo の画像は小さいサイズで使い、
   // Cosense にアップロードした画像はほかのサイトから表示できないため使わない
   const toEmbeddableImage = url => {
     const gyazo = /^https:\/\/(?:i\.)?gyazo\.com\/([0-9a-f]{32})/i.exec(url ?? '')
     if (gyazo) return `https://gyazo.com/${gyazo[1]}/max_size/40`
     return /^https?:\/\//.test(url ?? '') && !/^https:\/\/scrapbox\.io\//.test(url) ? url : null
   }
 
   // 画像を読み込めるか確かめる（Gyazo の GIF など、小さいサイズの画像を作れないものもある）
   const canLoad = url => new Promise(resolve => {
     const image = new Image()
     const timer = setTimeout(() => resolve(false), 5000)
     image.onload = () => {
       clearTimeout(timer)
       resolve(true)
     }
     image.onerror = () => {
       clearTimeout(timer)
       resolve(false)
     }
     image.src = url
   })
 
   const resolveIcons = async (lines, project) => {
     const pages = new Map()
     for (const line of lines) {
       for (const match of line.matchAll(/\[\[?([^[\]]+?)\.icon(?:\*\d+)?\]\]?/g)) {
         const path = /^\/([^/]+)\/(.+)$/.exec(match[1])
         const [projectName, title] = path ? [path[1], path[2]] : [project, match[1]]
         pages.set(`${projectName}/${title}`, [projectName, title])
       }
     }
     const icons = new Map()
     await Promise.all([...pages].slice(0, 100).map(async ([key, [projectName, title]]) => {
       try {
         const response = await fetch(`/api/pages/${encodeURIComponent(projectName)}/${encodeURIComponent(title)}`)
         const image = response.ok ? toEmbeddableImage((await response.json()).image) : null
         if (image && await canLoad(image)) icons.set(key, image)
       } catch {}
     }))
     return icons
   }
 
   const download = async format => {
     const lines = (scrapbox.Page.lines ?? []).map(line => line.text)
     if (lines.length === 0) return
     const title = scrapbox.Page.title ?? lines[0]
     if (format === 'md') {
       const project = scrapbox.Project.name
       const icons = await resolveIcons(lines, project)
       const markdown = cosenseToMarkdown(lines, {project, origin: location.origin, icons})
       save(markdown, toFileName(title, 'md'), 'text/markdown;charset=utf-8')
     } else {
       save(lines.join('\n'), toFileName(title, 'txt'), 'text/plain;charset=utf-8')
     }
   }
 
   // スマホの目次メニューにあるダウンロードボタンから呼ばれる
   document.addEventListener('zs:download', event => download(event.detail))
 
   scrapbox.PageMenu.addMenu({
     title: 'ダウンロード',
     image: DOWNLOAD_ICON
   })
   scrapbox.PageMenu('ダウンロード').addItem({
     title: 'Cosense 形式 (.txt)',
     onClick: () => download('txt')
   })
   scrapbox.PageMenu('ダウンロード').addItem({
     title: 'Markdown 形式 (.md)',
     onClick: () => download('md')
   })
 }

     button.title = label
     button.setAttribute('aria-label', label)
   }
 
   button.addEventListener('click', () => {
     const dark = !isDark(root.dataset.projectTheme)
     // プロジェクトのテーマと同じ明るさに戻したときは、設定を消してテーマに従う
     writeMode(dark === isDark(projectTheme) ? null : dark ? 'dark' : 'light')
     apply()
   })
 
   // 別のプロジェクトへの移動などで Cosense がテーマを設定し直したときは、そのテーマを基準に選び直す
   new MutationObserver(() => {
     const theme = root.dataset.projectTheme
     if (theme === appliedTheme) return
     projectTheme = theme || 'default'
     apply()
   }).observe(root, {attributes: true, attributeFilter: ['data-project-theme']})
 
   // ほかのタブで切り替えたときにも合わせる
   window.addEventListener('storage', event => {
     if (event.key === STORAGE_KEY) apply()
   })
 
   // ヘッダーの自分のアイコンの左隣に置く（ヘッダーが描き直されたときは置き直す）
   const mount = () => {
     const userMenu = document.querySelector('.navbar .navbar-menu > .user-menu-dropdown')
     if (userMenu && item.nextElementSibling !== userMenu) userMenu.before(item)
   }
 
   apply()
   mount()
   scrapbox.on('page:changed', mount)
   scrapbox.on('layout:changed', mount)
 }
